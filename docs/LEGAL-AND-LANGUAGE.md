# Legal pages, privacy controls and language routing

Updated 28 September 2026. Implementation draft, not a legal certification.

## Implemented and confirmed

- German /impressum and /datenschutz; English /en/legal and /en/privacy.
- Imprint distinguishes own content, outbound links, and unsolicited inbound links. No blanket liability waiver, outdated TMG/DDG boilerplate, or obsolete EU ODR platform link.
- Includes factual no-affiliation statement for unsolicited third-party links and a channel to report infringements. This does not prevent links or replace case-specific legal action.
- Full provider name carries © as requested. Wolfgang Zivny is listed without an academic title. Both email addresses appear normally. Registry and VAT details retained from the supplied original imprint, not independently certified.
- User confirmed Vercel Free/Hobby and united-domains for both mailboxes. No analytics, Vercel Analytics/Speed Insights, Resend, contact-form submission, external fonts or embedded social/video platforms found in the implemented website.
- Email hosting: united-domains GmbH, Gautinger Straße 10, 82319 Starnberg. No claim that an AVV is already signed.
- Cookie notice is informational: manual language choice only (180-day cookie); notice dismissal stores version and timestamp in localStorage. Application uses the latter for up to 180 days and removes expired records on the next visit. No optional tracking consent is collected.
- Contact dialog retains mailto, displays the address and writes only that address to the clipboard on request; it never reads the clipboard.
- Root middleware selects German for Germany, English otherwise; manual language cookie takes priority. Explicit language and legal URLs are not redirected. The application does not persist IP/country.
- Footer development paragraph removed at user's request. Concept-image labels and project notice in the imprint remain.
- Legal-page links have explicit page navigation, respect modified clicks, and larger footer hit areas. Native vertical scrollbar restored. Star finale is a full-screen photo with overlay copy.
